# Build a Gameplay Feature

Choose the smallest correct lane:

- Rule, resource, timer, cooldown, status, AI, trigger, pickup, door, or projectile behavior: Gameplay Script.
- Shared composition: Prefab Components.
- Placement-specific tuning: approved Scene Script-property overrides.
- Game presentation: `apps/web/src/game-runtime` game overlay.
- New reusable engine capability: native Component extension checklist.

Finish with `pnpm gameplay:generate`, focused tests, relevant Prefab/Scene harnesses, and `pnpm harness:vibe-coding`.
